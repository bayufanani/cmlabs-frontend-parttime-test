# CMLABS Frontend Part-Time Test

## Instruksi Instalasi
- Pastikan punya Node js terbaru
- Jalankan perintah berikut
```bash
npm install
```

## Instruksi menjalankan aplikasi
```bash
npm run dev
```
aplikasi akan berjalan pada http://localhost:3000
